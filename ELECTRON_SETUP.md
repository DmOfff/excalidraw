# Настройка Electron приложения с поддержкой стилуса ASUS ROG Flow Z13

## Что было сделано:

### 1. Добавлена поддержка силы нажатия (Pressure Sensitivity)
- В `src/components/App.tsx` добавлена обработка `event.pressure` для динамического изменения толщины линии
- Толщина линии варьируется от 0.5 до 10 в зависимости от силы нажатия стилуса
- Поддержка работает только для режима рисования пером (`pointerType === 'pen'`)

### 2. Настроены настраиваемые кнопки стилуса
В `src/constants.ts` добавлены новые константы для кнопок стилуса:
- `ERASER: 5` - кнопка ластика (удаляет элементы под курсором)
- `PAN: 12` - кнопка панорамирования (перемещение по холсту, как пробел)

В `src/components/App.tsx` добавлена обработка этих кнопок в `handleCanvasPointerDown`.

### 3. Добавлен режим ластика
В `src/shapes.tsx` добавлена новая форма "eraser" с иконкой ластика.

### 4. Упаковка в Electron приложение
Созданы файлы:
- `electron/main.js` - главный процесс Electron
- Обновлен `package.json` с зависимостями и скриптами для сборки

## Установка зависимостей:

```bash
npm install
```

Это установит все необходимые зависимости включая:
- electron
- electron-builder
- concurrently
- wait-on

## Запуск в режиме разработки:

```bash
npm run electron:start
```

Эта команда:
1. Запускает React приложение на порту 3000
2. Ждёт пока сервер будет готов
3. Запускает Electron приложение

## Сборка desktop приложения:

```bash
npm run electron:build
```

Собранные приложения будут находиться в папке `dist/`:
- **Windows**: NSIS установщик (.exe)
- **macOS**: DMG образ
- **Linux**: AppImage

## Настройка кнопок стилуса:

Кнопки стилуса ASUS ROG Flow Z13 работают через Pointer Events API:
- **Кнопка 1 (ластик)**: Удаляет элементы под курсором при нажатии
- **Кнопка 2 (панорамирование)**: Перемещает холст при перетаскивании

Если кнопки вашего стилуса используют другие коды, вы можете изменить их в файле `src/constants.ts`:

```typescript
export const POINTER_BUTTON = {
  MAIN: 0,
  WHEEL: 1,
  SECONDARY: 2,
  TOUCH: -1,
  ERASER: 5,    // Измените на нужный код кнопки
  PAN: 12,      // Измените на нужный код кнопки
};
```

## Тестирование силы нажатия:

1. Запустите приложение
2. Выберите инструмент рисования (линия, прямоугольник, круг и т.д.)
3. Используйте стилус для рисования
4. Меняйте силу нажатия - толщина линии должна изменяться динамически

## Дополнительные возможности:

- Сила нажатия работает только с инструментами рисования
- При использовании мыши или тачпада толщина линии остаётся стандартной
- Ластик удаляет только один элемент за раз (под курсором)
- Панорамирование работает так же, как зажатие пробела + перетаскивание

## Требования:

- Node.js >= 12.0.0
- npm или yarn
- Для сборки под Windows: Windows 10/11
- Для сборки под macOS: macOS 10.13+
- Для сборки под Linux: Linux x64

## Примечания:

- Приложение использует Pointer Events API, который поддерживается во всех современных браузерах
- Для корректной работы силы нажатия убедитесь, что драйверы стилуса установлены правильно
- В Electron приложение встроено в окно 1200x800 пикселей (можно изменить в `electron/main.js`)
